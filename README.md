# The Tank

A zero-player civilization simulator, broadcast 24/7. A sealed aquarium world where life arises, evolves,
may become sapient, may build civilizations, and may die. Nobody holds the controller.

**Status:** Phase 0 (design). See [`docs/DESIGN.md`](docs/DESIGN.md) and [`docs/ROADMAP.md`](docs/ROADMAP.md).
