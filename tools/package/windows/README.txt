THE TANK - Phase 1 test build for Windows
==========================================

1. Unzip this folder anywhere (for example, your Desktop).
2. Double-click  Tank.bat
3. Choose 1 to watch a new tank. It runs for a few seconds, then opens the
   viewer in your web browser.

In the viewer: Space = play/pause, arrow keys = step, click a dot to read
that person's thoughts, click an event on the right to jump to it.

Every run is saved in the "runs" folder:
  view.html      the viewer for that run (double-click to reopen)
  chronicle.txt  a readable history of important events
  thoughts.txt   the inner monologue of a sample of individuals
  summary.json   the numbers

Nothing is installed and nothing connects to the internet. To remove it,
delete the folder.

If Windows SmartScreen says "Windows protected your PC", click
"More info" then "Run anyway". (The program isn't code-signed.)
